## 1. The publisher's decision: stay with the same reader

Book 1's back matter teases a tween book (ages 8–12). The data says that's the wrong
Book 2.

**Evidence: T.R. Fosters' age-split series** (same niche, page 1, collected 2026-09-29)

| Book | Kindle BSR | Reviews |
|---|---|---|
| *Emotional Regulation for Parents* (general) | #73,316 | 146 |
| *…for Middle School Parents* | #720,538 | 49 |
| *…for High School Parents* | #1,115,729 | 82 |

The older-age spin-offs sell roughly 10–15× less than the main book. Splitting by age
sends each new book to a *new, smaller* buyer, so there's almost no read-through. A parent
who bought Book 1 for a 4-year-old has no use for a tween book this year.

**What maximizes royalties instead:** Book 2 serves the *same* parent (kids 2–7) with the
*next* problem she has. Then:
- Book 1 readers buy Book 2 (read-through: KU readers borrow both, so page reads double)
- Both books appear in each other's "Customers also bought" (same buyers)
- One Amazon Ads campaign can target the same competitor books for both
- A 2- then 3-book bundle becomes possible (T.R. Fosters sells a 6-in-1 at $26.99)

The tween book stays in the plan, later (Book 4+), once the series has readers whose kids
are growing up, or as the start of a second track.

**Fix for Book 1's teaser:** the current "What's Next" text promises the tween years. Book 1
needs an update anyway once Book 2 has an ASIN (to add the "read next" link and the review
link). Upload a revised manuscript then; the KDP listing, ASIN and reviews stay the same.

## 3. Recommendation: *The Listening Playbook*

Book 2 = **listening and cooperation scripts for parents of kids 2 to 7.** Why it wins:
1. **Biggest everyday pain.** Repeating yourself is daily for nearly every parent; meltdowns
   are a few times a week. More daily pain = more searches and more ad clicks.
2. **Proven, lasting demand.** The topic has carried best-sellers for decades (Faber's
   original *How to Talk So Kids Will Listen*, 1980, still sells), so it's evergreen.
3. **Direct series fit.** Same reader, same "Playbook" brand, same script card format.
   Each book sends readers to the other ("If it turns into a meltdown, see Book 1";
   "If they won't listen when calm, see Book 2").
4. **Clear gap to beat.** The big books are principle-based and long; the indie entrants
   are generic tip lists. Neither gives a lookup-by-moment script with a "what if they
   still don't?" follow-through step. That step is where parents fail, and where we win.

Full blueprint: `books/listening-playbook-02/brief.md` and `outline.md`.

## 6. Launch timing that helps both books
- Draft Book 2 now while Book 1 is in review and its first 30 days run (Amazon's
  new-release window).
- When Book 2 goes live: update Book 1's back matter with the Book 2 link, link both via
  KDP's series feature, then use Book 1's KDP Select promo days (free or Countdown) to
  push new readers into Book 2. One promo now lifts two books.
- Optional: list Book 2's ebook as a pre-order as soon as the manuscript is near final, so
  Book 1 can link to a live page sooner. Check KDP Help for the current pre-order rules and
  final-file deadline before setting a date (missing it blocks pre-orders for a year).
